Back to the coach

An exercise is one file (public/exercises/<id>.json): what it measures, what counts as right, what it says and in what order, how it is drawn, the words around it. Build one here from nothing, from a copy of a library exercise, or from a file; every change is checked. When it is whole it stands in the library on this browser, so the Recordings tab judges videos with it, the Animation tab draws it, and Try it live runs it in the coach. Download the file and drop it into the folder: the app reads the folder.

      Rep by rep

      Each rep the coach saw — counted, or an attempt it dropped — with every fault it had on the screen inside it and from when to when, whether the fault was said and at what moment, and the set-up faults in the pause before it. A fault has to hold for the persist time to be listed, as it has to before it is said; a flicker shorter than that is left out. Move a number above and this changes with it. Tap a rep to go to it.
